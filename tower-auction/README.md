# TOWER AUCTION

タワーをオークションで競り落とし、配置して王国を守るブラウザ向けタワーディフェンス。

## 起動
- `index.html` をブラウザで開く
- ビルドツールや追加ライブラリは不要

## 現在のプレイ可能機能
- 初期資金 1,000G
- ライバルAIとの簡易リアルタイム競売（3ロット）
- 6種類のタワーと能力差
- 自由配置型タワーディフェンス
- 3ウェーブの戦闘、敵撃破報酬、ステージ報酬
- 1x / 2x / 3x速度
- タワー強化、Gと結晶の獲得
- 失敗時のGペナルティ（所持Gの20%）
- ブラウザ内セーブ／ロード

## 今後の実装候補
秘密競売、タワー合成・レベル上限10、プレイヤースキルツリー、4種類の素材の個別管理、ボス戦、複数マップ、ランダムイベント、エンドレスモード、AIライバルの性格差。
